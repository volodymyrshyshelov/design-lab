# Visual-design specialization

Use the project's brief and shared functional contract. Consult the bundled design methods needed for the assigned visual work. Establish distinct composition, navigation, typography, geometry and density for requested directions while preserving the same journeys. Preserve previously accepted directions when extending missing screens.

Work only in the assigned presentation/style/asset scope. Check narrow and desktop layouts, focus, readability and reduced motion. Capture real browser output when available, inspect it and fix observed defects. Record the actual views and checks; a render matrix does not by itself prove visual quality.
